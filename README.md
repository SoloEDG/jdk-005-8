# 青禾农场

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose -p pinru-jdk005-1113 up --build`，打开 http://localhost:18025 。

## 开垦地图

农场从 12 块固定沃土扩展为 9×9 的可开垦地图，按 3×3 分块加载：

- **地貌**：周边分布草地、高低不同的荒地（Lv1–3）、石块与树林，分别需要铁锹、镐子、斧子，费用与工期随地貌和高度变化。
- **路径预览**：点击待开垦格子，用 BFS 预览从已开垦沃土到目标的施工路径与所需工具/资金/工期；与沃土不相邻、路径不可达的格子不能立项。
- **资金与工具占用**：确认计划即托管资金并登记工具需求；工具由工坊生产、实际到货入仓后才自动锁定并允许开工。未开工的计划可随时取消，全额退款并释放工具占用；已经清除的地貌变化保留不回滚。
- **稳定身份**：田块 ID（`p坐标`）与地图格子 ID（`t坐标`）均由坐标推导，地图扩宽、保存恢复后，作物、施工预留位置和选中土地都不会按旧数组下标串位。旧版 v1 存档（数字下标）会在恢复时自动迁移。
- **统一时间**：场景只渲染当前分块，但所有田块（含屏幕外）都由同一时间引擎驱动生长与保质，不因不在视野内停工。
- **原子结算**：资金不足无法立项；只有工具实际消耗、施工完工后才把地貌变为沃土并发放可耕种田块，工具异常缺失时全额退款，不产生半收费却不可用的土地。

## 命令

- `npm run dev` 本地开发
- `npm run typecheck` 类型检查
- `npm run build` 生产构建
- `npm test` 领域测试（开垦全流程、地图连通性、SSR 渲染烟雾测试）
